## 1. 系统简介

SeatFlow 是一款面向高校的自习座位预约系统，旨在解决"一座难求"与"占座不用"并存的问题，通过在线预约、签到确认、违约管理形成闭环，提升座位利用率和周转率。

**核心能力：**

- 🪑 在线预约座位，按整点时段精确占座
- ✅ 签到确认到场，杜绝占座不用
- ⏰ 自动提醒与超时取消，保障座位周转
- 🤖 智能助手，自然语言找座/预约
- 🔐 RBAC 权限管理，灵活分配管理角色

## 2. 登录与账户

### 2.1 登录

1. 打开系统首页，进入登录页面
2. 输入用户名和密码
3. 点击「登录」，系统验证后返回 JWT 令牌，自动跳转至对应端

> **注意：** 系统根据用户角色自动定向——学生进入学生端，管理员进入管理端。

### 2.2 默认账号

| 角色 | 用户名 | 密码 |
|---|---|---|
| 管理员 | admin | admin123 |
| 学生 | student1 | student123 |
| 学生 | student2 | student123 |

> ⚠️ 首次登录后请及时修改默认密码。

### 2.3 退出

点击页面右上角头像 → 「退出登录」，系统清除登录状态并跳转回登录页。

## 3. 学生端

### 3.1 首页 — 自习室列表

**入口：** 登录后默认进入首页

**功能说明：**

- 以卡片形式展示所有你有权限使用且处于开放状态的自习室
- 每张卡片显示：自习室名称、位置、开放时间段、当前空座数/总座数
- 属于特定院系的自习室仅对该院系学生可见，全校共享的自习室对所有学生可见

**操作：**

- 点击卡片 → 进入自习室详情与座位图

### 3.2 自习室详情与座位图

**入口：** 首页点击自习室卡片

**功能说明：**

- 展示自习室的基本信息（名称、位置、开放时间、所属院系）
- **座位图**以布局形式展示所有座位，不同状态用不同样式区分：
  - 🟢 **可选** — 绿色，可点击发起预约
  - 🔴 **已占** — 红色/灰色，当前时段已被预约
  - ⚫ **停用** — 灰色，座位暂不可用
- 座位上标注：座位编号、插座类型（无/固定插座/移动导轨插座）、位置标记（靠窗 🪟 / 靠走廊 🚶 / 中间）

**操作：**

- 点击可选座位 → 弹出预约时间选择面板

### 3.3 预约座位

**入口：** 座位图点击可选座位 / 搜索页选择结果 / 智能助手操作

**预约规则：**

| 规则 | 说明 |
|---|---|
| 时间单位 | 以整点小时为单位（如 8:00-10:00） |
| 最长时长 | 单次最多 4 小时（系统可配置） |
| 唯一性 | 同一时段同一座位不可重复预约 |
| 互斥性 | 同一时段不可预约多个座位 |
| 权限 | 需有该自习室的院系权限 |

**操作步骤：**

1. 在座位图点击可选座位
2. 在弹出的时间选择面板中选择日期和时段（起始整点 ~ 结束整点）
3. 确认预约信息（自习室、座位、时段）
4. 点击「确认预约」
5. 预约成功，状态变为 **待签到**

**取消预约：**

- 在「我的预约」中点击「取消」按钮
- 预约开始前取消：释放座位，不记违约
- 预约开始后、超时 15 分钟前取消：释放座位，不记违约
- 超时 15 分钟未签到后：系统自动取消，不可手动取消，记违约

### 3.4 签到

**入口：** 我的预约 → 签到按钮 / 签到页面

**功能说明：**

- 每个教室每天生成一个动态编码，编码在教室现场屏幕上展示
- 学生在 Web 端输入该编码完成签到

**签到规则：**

| 规则 | 说明 |
|---|---|
| 签到窗口 | 预约开始前 15 分钟 ~ 预约结束时间 |
| 编码有效期 | 与教室+日期绑定，每日更新 |
| 签到成功 | 预约状态变为 **使用中** |
| 编码错误 | 提示签到失败，可重新输入 |
| 超出窗口 | 不可签到，提示不在签到时间范围内 |

**操作步骤：**

1. 到达教室后，查看现场屏幕上的动态编码
2. 在系统中点击「签到」
3. 输入动态编码
4. 系统验证编码正确 → 签到成功

### 3.5 我的预约

**入口：** 导航栏 → 「我的预约」

**功能说明：**

- **当前预约**：展示所有未完成（待签到、使用中）的预约
  - 待签到状态：可「签到」或「取消」
  - 使用中状态：正常使用
- **历史预约**：展示所有已完成或已取消的预约记录
  - 支持「再次预约」：一键以相同座位、同时段发起新预约（如该时段可用）

**操作：**

- 点击「签到」→ 进入签到流程
- 点击「取消」→ 取消当前预约
- 点击「再次预约」→ 以历史记录为模板快速创建新预约

### 3.6 搜索座位

**入口：** 导航栏 → 「搜索」

**功能说明：**

支持多条件组合搜索，帮助你快速找到合适的座位。

**搜索条件：**

| 条件 | 说明 |
|---|---|
| 自习室 | 选择目标自习室 |
| 日期 | 选择预约日期 |
| 时间段 | 选择起始和结束整点 |
| 插座类型 | 无 / 有插座（固定/移动导轨） |
| 位置标记 | 靠窗 / 靠走廊 / 中间 |
| 院系 | 筛选院系自习室 |

**操作步骤：**

1. 填写搜索条件（可只填部分，支持模糊匹配）
2. 点击「搜索」
3. 结果列表展示：座位编号、可用时段、所属自习室、插座标记、位置标记
4. 点击结果中的座位 → 发起预约

### 3.7 违约记录

**入口：** 导航栏 → 「违约记录」

**功能说明：**

- 展示个人的所有违约记录
- 每条记录包含：违约时间、关联座位、关联自习室、违约原因（如"超时未签到"）
- 此页面仅可查看，不可操作

**违约原因：**

| 类型 | 说明 |
|---|---|
| 超时未签到 | 预约开始后 15 分钟仍未签到，系统自动取消并记录违约 |

### 3.8 智能助手

**入口：** 页面右下角聊天气泡 / 导航栏 → 「智能助手」

**功能说明：**

通过自然语言与智能助手对话，快速查询和预约座位，无需手动翻页操作。

**支持的能力：**

| 能力 | 示例 |
|---|---|
| 查询可用座位 | "今晚有空座吗？" "明天上午哪些自习室还有位置？" |
| 条件搜索 | "帮我找一个靠窗有插座的座位" "3楼有靠走廊的座位吗？" |
| 查询自己的预约 | "我今天定了哪？" "我明天有预约吗？" |
| 取消预约 | "取消我今晚的预约" |
| 帮助指引 | "怎么签到？" "预约规则是什么？" |

**操作步骤：**

1. 打开智能助手聊天窗口
2. 输入你的问题或需求（自然语言即可）
3. 助手返回结构化信息（座位列表、预约状态等）或执行操作（预约、取消）
4. 涉及操作类请求，助手会先确认再执行

## 4. 管理员端

### 4.1 仪表盘

**入口：** 管理端首页

**功能说明：**

提供系统运营数据的可视化概览，帮助管理员掌握全局。

**展示内容：**

| 指标 | 说明 |
|---|---|
| 预约率 | 已预约座位数 / 总可用座位数 |
| 使用率 | 已签到使用数 / 已预约数 |
| 违约率 | 违约次数 / 总预约次数 |
| 预约趋势 | 按日/周/月展示预约量变化 |
| 热门自习室 | 按预约量排名的自习室列表 |

**操作：**

- 可选择时间范围筛选数据（今日 / 本周 / 本月 / 自定义）

### 4.2 自习室管理

**入口：** 管理端导航 → 「自习室管理」

**功能说明：**

对自习室进行全生命周期管理。

**自习室属性：**

| 属性 | 说明 |
|---|---|
| 名称 | 自习室名称 |
| 位置 | 楼栋/楼层/房间号 |
| 所属院系 | 可为空（表示全校共享），或指定院系（仅该院系学生可见） |
| 开放时间 | 默认 07:00-22:00，可调整 |
| 状态 | 开放 / 关闭 |

**操作：**

| 操作 | 说明 |
|---|---|
| 新增 | 填写自习室信息，创建新自习室 |
| 编辑 | 修改自习室的名称、位置、院系、开放时间等 |
| 关闭/开放 | 切换自习室状态；关闭后学生对不可见，已有预约需处理 |
| 注销 | 逻辑删除，自习室不再出现在系统中 |

**注意事项：**

- 关闭自习室时，已有的预约会被通知并取消
- 管理员可临时调整单日开放时间

### 4.3 座位管理

**入口：** 管理端导航 → 「座位管理」

**功能说明：**

按自习室管理其下所有座位，维护座位库存。

**座位属性：**

| 属性 | 说明 |
|---|---|
| 座位编号 | 在自习室内唯一 |
| 所属自习室 | 关联的自习室 |
| 行列位置 | 座位在布局图中的行号和列号 |
| 插座类型 | 无 / 固定插座 / 移动导轨插座 |
| 位置标记 | 靠窗 / 靠走廊 / 中间 |
| 状态 | 可用 / 停用 |

**操作：**

| 操作 | 说明 |
|---|---|
| 新增 | 单个或批量添加座位，指定行列位置和属性 |
| 编辑 | 修改座位的属性（插座类型、位置标记等） |
| 停用/启用 | 切换座位状态；停用后不可预约，但保留历史记录 |
| 注销 | 逻辑删除，座位不再出现在系统中 |

**操作步骤（批量添加）：**

1. 选择目标自习室
2. 设定行数和列数
3. 批量生成座位（可统一设置插座类型和位置标记）
4. 逐个调整特殊座位的属性

### 4.4 预约管理

**入口：** 管理端导航 → 「预约管理」

**功能说明：**

查看全局预约记录，并支持代客操作处理特殊情况。

**展示内容：**

- 预约列表（分页），支持按状态、自习室、日期、学生等条件筛选
- 每条记录包含：学生姓名、自习室、座位编号、预约时段、状态

**操作：**

| 操作 | 说明 |
|---|---|
| 查看详情 | 查看某条预约的完整信息 |
| 代客预约 | 管理员代替学生创建预约，操作记录标注"管理员操作" |
| 代客取消 | 管理员代替学生取消预约 |

**代客预约步骤：**

1. 点击「代客预约」
2. 输入学生用户名
3. 选择自习室、座位、时段
4. 确认预约

### 4.5 签到编码管理

**入口：** 管理端导航 → 「签到编码」

**功能说明：**

查看各教室当日的签到动态编码，供现场展示使用。

**展示内容：**

- 按自习室列出当日生成的动态编码

**操作：**

- 选择自习室 → 查看当日编码

### 4.6 违约管理

**功能说明：**

### 4.7 用户管理

**操作：**

| 操作 | 说明 |
|---|---|
| 查看用户列表 | 分页展示所有用户，含用户名、院系、角色等 |
| 分配角色 | 为用户分配一个或多个角色（权限取并集） |
| 移除角色 | 移除用户的某个角色 |

**分配角色步骤：**

**入口：** 管理端导航 → 「角色管理」

**默认角色：**

| 角色 | 说明 |

| service_admin | 查看预约/违约记录，代客预约/取消 |
| viewer | 仅查看预约/违约记录 |

**权限项：**

| 权限编码 | 说明 |
|---|---|
| `reservation:view` | 查看预约记录 |
| `violation:view` | 查看违约记录 |
| `reservation:manage` | 为用户预约和取消预约 |
| `seat:manage` | 座位登记和注销 |
| `room:manage` | 自习室登记和注销 |
| `system:config` | 调整系统参数 |
| `role:manage` | 角色和权限管理 |
| `user:manage` | 用户角色分配 |

**操作：**

| 操作 | 说明 |
|---|---|
| 新增角色 | 创建自定义角色，勾选权限 |
| 编辑角色 | 修改角色名称、调整权限 |
| 删除角色 | 删除自定义角色（默认角色不可删除） |

> **注意：** 管理端菜单根据当前用户角色权限动态展示，无权限的功能不会出现。

### 4.9 系统参数配置

**入口：** 管理端导航 → 「系统参数」

**功能说明：**

调整系统运行参数，参数修改后即时生效。

**可配置参数：**

| 参数名 | 默认值 | 说明 |
|---|---|---|
| `max_reservation_hours` | 4 | 单次最大预约小时数 |
| `check_in_remind_before_min` | 15 | 签到提前提醒时间（分钟） |
| `check_in_warn_after_min` | 10 | 签到逾期警告时间（分钟） |
| `check_in_cancel_after_min` | 15 | 签到逾期自动取消时间（分钟） |

**操作步骤：**

1. 进入系统参数页面
2. 修改目标参数的值
3. 点击「保存」
4. 参数即时生效，无需重启系统

## 5. 预约规则与违约机制

### 5.1 预约规则总览

```
┌─────────────────────────────────────────────────┐
│              预约生命周期                          │
│                                                   │
│  创建预约 → 待签到 → 签到 → 使用中 → 到时 → 已完成  │
│               │                                   │
│               └→ 超时15min未签到 → 已取消(违约)     │
│               │                                   │
│               └→ 手动取消 → 已取消                  │
└─────────────────────────────────────────────────┘
```

### 5.2 时间规则详解

| 时间节点 | 触发动作 |
|---|---|
| 预约开始前 15 分钟 | 📩 推送提醒："您的预约即将开始，请按时签到" |
| 预约开始后 10 分钟 | 📩 推送警告："您还未签到，请尽快签到，否则 5 分钟后预约将被取消" |
| 预约开始后 15 分钟 | 📩 推送通知 + 自动取消预约 + 记录违约 |

### 5.3 取消与违约规则

| 场景 | 结果 |
|---|---|
| 预约开始前主动取消 | ✅ 释放座位，不记违约 |
| 预约开始后、超时 15 分钟前主动取消 | ✅ 释放座位，不记违约 |
| 超时 15 分钟未签到 | ❌ 系统自动取消，记录违约，不可手动取消 |

## 6. 消息通知说明

系统采用 **WebSocket + 邮件** 双通道推送：

| 通道 | 适用场景 | 说明 |
|---|---|---|
| WebSocket | 用户在线时 | 页面内实时弹出通知，优先使用 |
| 邮件 | 用户离线时 | WebSocket 消息未送达时，邮件兜底发送 |

**通知类型：**

| 通知 | 触发时机 |
|---|---|
| 预约提醒 | 预约开始前 15 分钟 |
| 签到警告 | 预约开始后 10 分钟未签到 |
| 违约通知 | 预约开始后 15 分钟未签到，自动取消 |
| 预约成功 | 预约创建成功 |
| 取消通知 | 预约被取消（主动或系统自动） |

## 7. 常见问题

### Q1：为什么我看不到某个自习室？

自习室可能属于特定院系，仅该院系学生可见。请确认你的院系信息是否正确。全校共享的自习室对所有学生可见。

### Q2：预约时间最多可以选多长？

默认单次最多 4 小时，以整点为单位。管理员可在系统参数中调整此上限。

### Q3：签到编码在哪里获取？

签到编码显示在教室现场的屏幕上，每天更新。你需要在 Web 端签到页面输入该编码。

### Q4：错过了签到时间怎么办？

预约开始后 15 分钟内未签到，系统会自动取消预约并记录违约。建议及时关注通知提醒。

### Q5：违约记录可以删除吗？

违约记录由系统自动生成，不可手动删除。请保持良好的预约习惯，按时签到。

### Q6：智能助手可以做什么？

智能助手支持自然语言交互，可以帮你查询可用座位、搜索特定条件座位、查看预约、取消预约，以及回答使用相关问题。

### Q7：管理员可以代替学生预约吗？

可以。在管理端「预约管理」中点击「代客预约」，输入学生用户名后即可代替操作，操作记录会标注"管理员操作"。

### Q8：系统参数修改后需要重启吗？

不需要。系统参数修改后即时生效。

### Q9：一个用户可以拥有多个角色吗？

可以。一个用户可分配多个角色，权限取并集。例如同时拥有 `room_admin` 和 `service_admin` 角色的用户，可以管理自习室/座位，也可以代客预约/取消。

### Q10：关闭自习室后已有的预约怎么处理？

关闭自习室时，系统会通知相关学生并自动取消该自习室的所有未完成预约。
