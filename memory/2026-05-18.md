## 修复的 Bug 清单

### Bug 1：登录输错密码/账号无友好提示
- **根因**：后端 BusinessException 默认 code=400，登录错误应返回 401
- **修复**：AuthServiceImpl 中用户不存在/密码错误改为 `new BusinessException(401, "...")`，GlobalExceptionHandler 根据业务 code 动态设置 HTTP 状态码

### Bug 2：账号密码正确无法登录
- **根因1**：SecurityConfig 中 `/api/auth/login` 配置 `.anonymous()`，已登录用户（localStorage 有旧 token）再访问登录接口被 403 拒绝
- **修复1**：改为 `.permitAll()`
- **根因2**：前端 api.ts 响应拦截器返回 `response.data`（解包一层），但所有页面用 `res.data.code` 访问（相当于双层解包），导致 `res.data.code` 永远 undefined，所有页面逻辑走不进 success 分支
- **修复2**：响应拦截器改为返回 `response` 完整对象
- **根因3**：前端登录时未清除旧 token，axios 自动携带旧 token
- **修复3**：登录前先 `localStorage.removeItem('token')`

### Bug 3：页面无关键数据
- **根因**：上述 Bug 2 的响应拦截器问题 + 数据库缺少种子数据
- **修复**：修复拦截器 + 直接向数据库插入预约/违约/签到编码种子数据

### Bug 4：学生端搜索页面未实现
- **修复**：创建 `Search.tsx` + `services/search.ts`，对接后端 `GET /api/seats/search`

### Bug 5：座位图点击无预约功能
- **修复**：RoomDetailPage 实现座位点击预约弹窗，支持选择日期时间

### Bug 6：管理端 check-in-codes 路由指向错误
- **修复**：创建 `CheckInCodeManage.tsx`，路由指向正确组件
